# NEXORA DESIGN ENGINE — релиз 1.2.1

Статус: отдельный стабильный Worker развернут по адресу https://nexora-design-engine.audiliga.workers.dev/. Он не заменяет и не изменяет NEXORA V1, V2 или их Production. Активный рендерер — Cloudflare Workers AI FLUX.2 Klein 9B; Moondream проверяет сохранение типа помещения. Полный рендер через стабильный Worker был заблокирован исчерпанием бесплатной дневной квоты, поэтому live end-to-end результат пока не сохранён. Платный fallback отключён.

## Назначение

Создать собственную систему проектирования интерьеров, которая:
1. анализирует оригинальную фотографию и известные ограничения помещения;
2. формирует самостоятельную дизайнерскую концепцию до вызова графической модели;
3. переводит концепцию в структурированное задание;
4. передаёт задание независимому адаптеру графической модели;
5. оценивает результат по качеству дизайна, стилю, геометрии, функциональности и реализму;
6. сохраняет происхождение результата, параметры и оценки.

## Защитные правила проекта

- V1, V2, Production и существующие deployments не изменять.
- Эксперименты вести только в отдельной ветке.
- Не импортировать и не показывать старые неудачные генерации.
- Эталонный тест — только оригинальная фотография пользователя, когда она будет предоставлена.
- Не заменять её фотографиями из интернета или синтетическими изображениями.
- Исходник хранить отдельно от результатов; не перезаписывать.
- Не объявлять модель победителем по опубликованным benchmark-таблицам.
- Не подключать платные API, не создавать оплачиваемые ресурсы и не запускать крупные загрузки моделей без отдельной оценки стоимости и согласования.
- Любой критический дефект геометрии или функциональности блокирует выдачу, даже если изображение красиво.

- [x] Vision Analysis JSON Schema с confidence, uncertainty и только гипотетическими размерами.

- [x] Адаптер Cloudflare Workers AI для Moondream 3.1: передача оригинала как base64 data URI, запрос структурированного анализа, fail-closed разбор JSON.
- [x] Room Design Pipeline: анализирует фото через адаптер, формирует реестр ограничений и три Design Brief.
- [x] Архитектурные элементы и проёмы, обнаруженные Vision, консервативно помечаются как preserve; мебель, техника и прочие объекты остаются unknown.
- [x] Vision не может объявить объект replaceable. Только явные пользовательские ограничения определяют, что заменять.
- [x] Конфликт пользовательского указания с Vision фиксируется в реестре; приоритет у пользователя.
- [x] Quality Gate с весами, порогом и критическими блокировками.
- [x] Проверка различий между тремя концепциями.
- [x] Нативный адаптер Cloudflare Workers AI FLUX.2 Klein 9B для image-to-image генерации.
- [x] Три конкретных кухонных направления: ivory/limestone architectural, olive/smoked-oak Mediterranean, walnut/stone expressive.
- [x] D1 dispatch ledger, защита от повторной отправки, восстановление уже сохранённого результата.
- [x] Moondream room-identity gate: результат отклоняется, если тип комнаты изменился или классификация неоднозначна.
- [x] Жёсткий общий лимит 3 генерации в сутки; платные резервные провайдеры отключены.
- [x] Стабильный отдельный Worker 1.2.1 и проверка /api/health, главной страницы и API трёх концепций.

Это не тест на оригинальном фото пользователя и не доказательство профессионального качества на её помещении. ## Принцип разработки

Сначала система должна научиться понимать пространство и проектировать, затем — управлять генерацией, затем — проверять результат. Генеративная модель является сменным рендер-движком, а не носителем всей логики NEXORA.
