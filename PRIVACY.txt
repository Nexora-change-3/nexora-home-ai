NEXORA HOME AI 0.4.4: проекты, заметки, размеры, планы квартир, исходные фотографии и сметы хранятся в IndexedDB браузера на устройстве. Они не отправляются в GitHub вместе с кодом приложения. При экспорте резервная копия создаётся в выбранном пользователем файле; при импорте данные добавляются в локальную базу.

Только после нажатия пользователем кнопки «Создать визуализацию» приложение отправляет одну фотографию комнаты и одну фотографию желаемого стиля на настроенный пользователем Cloudflare Worker для обработки моделью FLUX.2 klein 4B (Cloudflare Workers AI). Изображения передаются для выполнения запроса и не загружаются в репозиторий NEXORA. Результат сохраняется в локальном хранилище Safari. Не отправляйте фотографии, которые не хотите передавать внешнему AI-провайдеру.

Секрет Cloudflare API хранится только в настройках Cloudflare Worker. В приложении сохраняется отдельный пользовательский ключ доступа к Worker в локальном хранилище браузера.
